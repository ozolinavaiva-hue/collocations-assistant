# Collocations Assistant V3

AI-powered extraction for advanced English learners. Public UI + Netlify serverless function.

## Deployment (Netlify)
1. Extract this ZIP. Upload the **folder** to a Netlify site using Netlify Drop or the site's Deploys page. Netlify must build the site with functions support.
2. Create a free Google AI Studio API key: https://aistudio.google.com/apikey
3. In Netlify: Site configuration → Environment variables → Add variable:
   `GEMINI_API_KEY` = your key. Set scope to Functions (or all scopes).
4. **Trigger a new deploy** after adding the variable.
5. Open the site, paste 100+ characters, and click Extract collocations.

If you see "Site owner must configure GEMINI_API_KEY", step 3 or 4 is missing.
If you see an AI provider error, check the API key, model availability and free quota.
The default model is `gemini-2.5-flash`; optionally set `GEMINI_MODEL` in Netlify.
A deployed static HTML page alone cannot run the backend without Netlify Functions.

## Accuracy and limitations
- Only contiguous expressions present in the supplied text are accepted.
- The exact original source sentence is selected by server-side code.
- New example sentences and meanings are generated by AI.
- CEFR C1/C2 labels are **estimates**.
- These candidates are **NOT** verified against COCA or OZDIC. Live access to those databases is not included.
- No persistent text storage in this code, but pasted text is sent to the Gemini API.
- Free tier usage is limited and availability may change.
- Public endpoints can be abused. For classroom-scale use, configure Netlify rate limiting or CAPTCHA before broad sharing.
- Avoid sharing confidential or personal student data.
